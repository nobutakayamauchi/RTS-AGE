# AGE Planning Dry-run Fixture

This directory contains checked-in sample artifacts for the AGE planning dry-run.

These files are fixtures, not runtime output.

Runtime output belongs under:

```text
outputs/
logs/
runs/
```

Those runtime paths are ignored except for `.gitkeep` placeholders.

The fixture keeps a stable example of the planning package so tests and reviews can inspect expected shape without committing fresh generated output after every run.
