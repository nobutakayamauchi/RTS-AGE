# POSITION: RTS-AGE (RTS Agentic Gateway & Execution Lab)

- RTS-AGE is the RTS Agentic Gateway & Execution Lab.
- RTS-AGE is an implementation lab, not a canonical source.
- RTS-AGE may read canonical RTS repositories and generate patch proposals.
- RTS-AGE must not store canonical RTS records, skill manifests, pack manifests, drive manifests, talent registry data, or signal feed registry data as source of truth.
- RTS-AGE may produce validators, dry-run runners, adapters, reports, generated drafts, and patch bundles.
- Existing free-claude-code runtime/proxy code remains upstream-derived implementation material and must not be confused with RTS core.
- If used operationally, RTS-AGE should be registered in RTS-Talent-Registry as an external runtime/tool candidate.
