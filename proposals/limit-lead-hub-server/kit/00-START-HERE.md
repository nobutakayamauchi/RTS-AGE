# 限界開発スターターキット

Version: v0.1.0

## これは何か

AIとの会話が長くなった、作業が数日止まった、担当AIや端末が変わった――そんな時でも、開発をゼロから説明し直さず再開するための最小キットです。

コードを書けるかどうかは問いません。必要なのは、現在地・次の一手・判断理由を短い記録として残すことだけです。

## 最初の15分

1. `01-PROJECT-SNAPSHOT.md` に、今わかっている事実を書く。
2. `02-NEXT-ACTION.md` に、次に行う作業を一つだけ書く。
3. 重要な判断を `03-DECISION-LOG.md` に残す。
4. 新しいAIへ `04-AI-HANDOFF-PROMPT.md` を貼り、上のファイルを読ませる。
5. 作業終了時に `06-STOP-AND-RESTART-CHECKLIST.md` を更新する。

## 4つの原則

### 1. 事実と推測を分ける

「動いた」「確認した」は証拠のある事実だけに使います。未確認は未確認と書きます。

### 2. 次の一手は一つにする

巨大な計画より、今すぐ実行できる一手を固定します。失敗した場合の停止条件も一緒に書きます。

### 3. 壊してはいけない場所を先に書く

本番環境、顧客データ、秘密情報、既存サービスなど、触ってはいけない範囲を明示します。

### 4. 再開に必要な情報だけ残す

会話全文を保存する必要はありません。現在地、判断、証拠、次の一手、復旧方法があれば再開できます。

## 推奨フォルダ

```text
project/
├─ 01-PROJECT-SNAPSHOT.md
├─ 02-NEXT-ACTION.md
├─ 03-DECISION-LOG.md
├─ 04-AI-HANDOFF-PROMPT.md
├─ 05-RTS-LITE-TEMPLATE.md
└─ 06-STOP-AND-RESTART-CHECKLIST.md
```

## 秘密情報について

パスワード、APIキー、アクセストークン、秘密鍵、顧客の個人情報は、このキットやAIへの引継ぎ文へ直接書かないでください。「どこに安全に保存されているか」だけを記録します。

## 完成の目安

新しいAIまたは別の人が、10分以内に次の一手を説明できれば引継ぎ成功です。
