# STOP AND RESTART CHECKLIST

作業を止める前と再開する時に使う。

## 止める前

- [ ] 最後に成功した地点を書いた
- [ ] 失敗した地点とエラーを保存した
- [ ] 現在のブランチ／環境を書いた
- [ ] 未コミット・未保存の変更を確認した
- [ ] 次の一手を一つに絞った
- [ ] 成功条件と停止条件を書いた
- [ ] 壊してはいけない範囲を更新した
- [ ] パスワードや個人情報を記録へ貼っていない
- [ ] バックアップまたは復旧方法を確認した

## 再開する時

- [ ] `01-PROJECT-SNAPSHOT.md` を読む
- [ ] `03-DECISION-LOG.md` の最新判断を読む
- [ ] 対象環境とブランチが一致するか確認する
- [ ] 既存サービスが動いているか確認する
- [ ] `02-NEXT-ACTION.md` の一手だけを実行する
- [ ] 出力を証拠として残す
- [ ] 成功後に現在地を更新する
